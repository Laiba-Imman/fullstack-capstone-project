# GiftLink User Story

## User Story Template

**As a** user who has household items I no longer need,

**I want** to create a listing and search/filter available items,

**So that** other people can reuse useful household items for free instead of buying new ones.

## Acceptance Criteria

- User can register.
- User can login securely.
- User can view available items.
- User can search for items.
- User can filter items by category.
- User can view item details.
- User can update profile information.
